# 画像スロット一覧（全45枠）

`src/images.json` の `src` に画像URLを入れると、その枠が実画像に切り替わります。
空欄の枠はプレースホルダー表示のままなので、**1件ずつ埋めていけます**。

```bash
# URLを入れたら
node build.mjs
```

`alt` は空欄なら「用途」から自動補完します。ページヘッダーなど見出しの背後に敷く写真は
装飾扱いとして `alt=""` になります（読み上げ時にノイズにならないように）。

## 記入例

```json
{
  "id": "index-01",
  "page": "index",
  "kind": "写真",
  "label": "メインビジュアル ／ 屋根上でのソーラーパネル施工",
  "size": "2000×1125px 以上",
  "eager": true,
  "src": "https://kanayama-ss.com/wp-content/uploads/2023/07/xxxx.jpg",
  "alt": "屋根の上でソーラーパネルを設置する職人"
}
```

`eager` が `true` の枠は最初に表示される画像です（先読みします）。触らなくて構いません。

プロトタイプは現行より枠を絞った構成なので、**基本的に現行素材だけで足りる見込み**です。

ただし下層ページのヘッダー背景（`*-header`、**横長 1920×540px 相当**）は現行サイトに
同用途の画像がない可能性があります。既存写真のトリミングで足りるかは実物を見てからの判断です。
