# 画像スロット一覧（全44枠）

`src/images.json` の `src` にURLを入れると実画像に切り替わります。空欄はプレースホルダー表示のまま。

ローカルのファイル（`assets/img/...`）を指定した場合、**実ファイルが置かれるまではプレースホルダーのまま**
なので、壊れ画像にはなりません。

割り当ては `prototype/assign.html` をブラウザで開くとクリックで行えます。
