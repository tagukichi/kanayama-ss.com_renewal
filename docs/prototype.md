# デザインプロトタイプ

現行サイトから確認できた **配色・構成・公開情報** のみをもとに作成した、静的HTMLのデザイン案です。

## 見かた

| ファイル | 用途 |
|---|---|
| `prototype/preview.html` | **全13ページを1ファイルにまとめた確認用。**まずこれをブラウザで開いてください |
| `prototype/index.html` ほか | 通常の静的サイト（ページごとに分割） |
| `prototype/preview.artifact.html` | 共有リンク公開用（自動生成／直接編集しない） |

## 重要：仮のもの

| 項目 | 状態 |
|---|---|
| 写真 | **すべてプレースホルダー。** 枠内に「どの写真を・どのサイズで」入れるか明記しています |
| テキスト | **公開情報をもとにした仮原稿。** 原文ではないため、実原稿での差し替えが必要です |
| 電話番号・住所 | `03-XXXX-XXXX` `〒130-00XX` のように伏せ字 |
| 会社概要・募集要項 | 未確定の項目は `［支給待ち］` と表示 |
| ロゴ | 屋根＋パネルを模した仮マーク（SVG）。正式なロゴデータで差し替え |
| フォント | `acumin-pro-extra-condensed`（Adobe Fonts）の代替として **Barlow Condensed** を使用 |

## 編集とビルド

ヘッダー・フッターは共通パーツです。**`prototype/` を直接編集せず、`src/` を編集して再ビルド**してください
（`prototype/` はビルドのたびに作り直されます）。

```
src/layout.html        全ページ共通の外枠
src/partials/          ヘッダー・フッター（→ WPの header.php / footer.php になる）
src/pages/*.html       各ページの本文（先頭の <!--meta --> でタイトル等を指定）
src/assets/style.css   デザインシステム（トークン → 部品 の順で定義）
src/assets/app.js      モバイルメニュー・スクロール表示
```

```bash
node build.mjs   # → prototype/ を再生成
```

## デザインの決めごと

- **配色**：現行サイトの実測値をそのまま継承（グリーン `#179918` / サブ `#219824` / アクセント `#FF6900`）。
  ニュートラルは純グレーではなく、わずかに緑を含んだ `#161A15` `#5B655A` `#DEE3DC` `#F4F6F2` で統一
- **書体**：英字 Barlow Condensed ＋ 和文 Noto Sans JP（本文）/ Noto Serif JP（理念・代表メッセージ）
- **モチーフ**：ソーラーパネルの格子と屋根の勾配。角丸を使わず、細い罫線と斜線で構成
- **レイアウト**：左に「英字ラベル＋和文見出し」、右に本文の非対称グリッド（`.rail`）

## 現行サイトからの改善点

- `h1` を各ページ1つに是正（現行はトップ5個・採用4個）
- `/privacy/` だけ浮いていたテンプレートを共通化
- ヘッダーの事業案内をドロップダウンに集約（ページ構成そのものは変更なし）
- 画像は `aspect-ratio` で領域を確保（読み込み時のガタつき防止）

## 検証済み

13ページ × 3幅（1440 / 768 / 390px）を Chromium で確認。
横スクロールなし・JSエラーなし・`h1` 重複なし。

> 注意：検証環境は外部通信が遮断されているため Google Fonts が読み込めず、
> スクリーンショット上の書体は代替フォントです。**レイアウトは検証済みですが、
> 最終的な字面は実際のブラウザでご確認ください。**

## 次の工程（WordPress テーマ化）

1. `src/partials/` → `header.php` / `footer.php`
2. `src/pages/index.html` → `front-page.php`
3. 下層固定ページ → `page.php`（＋必要に応じて個別テンプレート）
4. `works.html` / `news.html` → `archive-works.php` / `home.php`
5. `works-detail.html` → `single-works.php`
6. `works` カスタム投稿タイプとカスタムフィールドの定義
7. お問い合わせフォームをフォームプラグインに接続
