作成日: 2026-08-23

## 最優先：まずこのどちらかを

現在この作業環境は、ネットワークポリシーにより **kanayama-ss.com を含む全外部サイトへの直接アクセスが遮断**されています（curl / WebFetch とも 403・EGRESS_BLOCKED）。
そのため HTML・CSS・画像を自分でダウンロードできません。

**解決策は2つ。どちらか一方で構いません。**

### 方法① 環境のネットワーク許可設定を変更する（最速・推奨）
Claude Code の環境設定で `kanayama-ss.com` への egress を許可していただければ、
**以降の A-1 / A-2 は自分で全て取得できます**（支給不要）。
→ 設定箇所: https://code.claude.com/docs/en/claude-code-on-the-web （環境のネットワークポリシー）

### 方法② サイトを丸ごとダウンロードして渡す
ローカルPCで以下のいずれかを実行し、生成されたフォルダを zip でご共有ください。
これ1つで A-1（素材）と A-2（原稿）が同時に解決します。

```bash
# macOS / Linux（wget）
wget --mirror --convert-links --adjust-extension --page-requisites --no-parent \
     --restrict-file-names=windows https://kanayama-ss.com/

# Windows なら HTTrack Website Copier（GUI）でも可
```

※ うまく取れない場合は、各ページをブラウザで開き
`Ctrl/Cmd + S` →「**ウェブページ、完全**」で保存したものでも代用できます（全13ページ分）。

## A. 必須（これが無いと着手できない）

### A-1. 画像素材一式
「現在サイトで使っている素材をそのまま使う」方針のため、**元画像が必須**です。

- 対象: 全13ページ、計 **約90点以上**（`/solar/` 18点、`/interview/` 13点、`/recruit/` 11点、`/works/` 詳細 各10〜11点 など）
- **欲しい形態（優先順）**
  1. WordPress 管理画面 → メディアライブラリ の**元データ一式**（＝サーバー上の `/wp-content/uploads/` フォルダ）
  2. 上記が無理なら、方法②のサイト丸ごとダウンロード（表示サイズの画像になる点に注意）
- **ロゴは別途、ベクターデータ**（`.ai` / `.svg` / `.eps`）をいただけると仕上がりが大きく変わります

### A-2. 全ページの原稿テキスト
現状、検索経由の「要約」しか取得できておらず、**原文が1文字も手元にありません**。
コピーを勝手に書き換えることはできないため、原文が必要です。

- 対象: 全13ページ（トップ / 私たちの想い / 太陽光発電・蓄電 / 電気・水道工事 / 会社案内 / 採用情報 / 代表メッセージ / 社員紹介 / お問い合わせ / 工事実績一覧 / 工事実績詳細 / お知らせ / プライバシーポリシー）
- 形態: 方法②のHTMLでも、テキスト/Word/スプレッドシートでも可
- **あわせて確認したいこと**: リニューアルに際して**文言を変更する箇所はあるか**（そのままなら「変更なし」で結構です）

### A-3. WordPress 環境の情報
最終的にテーマ化するため、現行の構成を知る必要があります。

| 項目 | 補足 |
|---|---|
| WordPress バージョン | |
| 現在のテーマ名 | 自作か、既製テーマか |
| **プラグイン一覧** | 管理画面のスクリーンショットで可。特に **フォーム / カスタム投稿タイプ / SEO** 系 |
| `works` の投稿タイプ名 | カスタム投稿タイプか、通常投稿か |
| `works` のカスタムフィールド | 工事内容・エリア・施工日など、どんな項目を持っているか |
| `works` / `news` のタクソノミー | カテゴリー・タグの有無と内容 |
| 各固定ページのスラッグ | `/concept/` `/solar/` … の対応関係 |
| PHP バージョン | |
| サーバー・ホスティング会社 | |

> ℹ️ `/wp-json/wp/v2/types` が **403** を返すため、外部から自動判別できませんでした（セキュリティ系プラグインで REST API が制限されている可能性があります）。

## B. 品質を上げるために欲しい（無くても進行可能）

### B-1. Adobe Fonts（Typekit）のライセンス状況
現行サイトは英字見出しに **`acumin-pro-extra-condensed`**（Adobe Fonts）を使用しています。
このフォントがサイトの見た目を決定づけているため、扱いを決める必要があります。

- **契約が生きている場合** → Typekit のキットID／Creative Cloud アカウントの継続可否
- **契約が無い／解約予定の場合** → 代替フォントに切り替えます（例: Oswald / Barlow Condensed / Archivo Narrow など無料の Google Fonts）

**→ 「継続する / 代替にする」のご判断だけでも先にいただけると助かります。**

### B-2. お問い合わせフォームの仕様
- 入力項目の一覧（必須/任意の区別も）
- 送信先メールアドレス
- 自動返信メールの本文
- 使用プラグイン（Contact Form 7 / Snow Monkey Forms / WPForms など）
- reCAPTCHA 等のスパム対策の有無

### B-3. 会社情報の正データ
フッター・会社案内で使うため、正確な値をお願いします。
- 正式社名 / 所在地 / 電話番号 / FAX / 営業時間 / 定休日
- 設立年月 / 資本金 / 代表者名 / 従業員数 / 建設業許可番号・電気工事業登録番号
- 沿革

### B-4. 計測タグ類
- Google Analytics（GA4）測定ID
- Google Search Console の登録状況
- Google タグマネージャー / 広告タグの有無

## C. リニューアルの方向性（ご判断いただきたいこと）

デザインを一新するにあたり、以下を伺えると狙いを外しません。

1. **今のサイトの、どこに不満がありますか？**（例: 古い / スマホで見にくい / 高級感がない / 採用に効かない）
2. **どちらを優先しますか？** 「工事の受注獲得」寄り / 「採用・人材確保」寄り
3. **好みのトーン**（例: 誠実で堅実 / モダンでシャープ / 親しみやすい / 職人の力強さ）
4. **参考にしたいサイト**があれば2〜3つURLを（同業でなくて構いません）
5. **ブランドカラーの扱い**: 現行のグリーン `#179918` ＋ オレンジ `#FF6900` を維持しますか？
6. **公開希望時期**
