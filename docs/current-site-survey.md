# 現行サイト調査レポート — kanayama-ss.com

調査日: 2026-08-23 / 対象: https://kanayama-ss.com/

---

## 0. 調査方法と制約（先に読んでください）

本作業環境はネットワーク egress ポリシーにより、**外部サイトへの直接 HTTP 取得が全面的に遮断**されています。

| 経路 | 結果 |
|---|---|
| `curl https://kanayama-ss.com/` | `CONNECT tunnel failed 403`（ポリシー拒否） |
| WebFetch（kanayama-ss.com） | `EGRESS_BLOCKED` |
| WebFetch（example.com で対照テスト） | `EGRESS_BLOCKED` → 特定ドメインではなく全ドメイン遮断 |
| web.archive.org | 取得不可 |

そのため **HTML / CSS / JS / 画像ファイルのダウンロードは現状できません。**

実際に取得できたのは以下の2経路のみです。

1. **外部 MCP サーバー経由のレンダリング解析**（コンテナ外で実行されるためポリシー対象外）
   → 各ページの `title` / 配色 / フォント / 構造カウント（実測値・信頼度高）
2. **Web検索経由の本文要約**
   → コンテンツの骨子（**要約であり原文ではない**。コピーとしては使用不可）

→ 原稿テキストと画像素材は支給が必要です。`docs/request-list.md` 参照。

- **CMS**: **WordPress（確度：高）**
  - 根拠1: 全ページで Gutenberg コアパレット色（`#FF6900` `#FCB900` `#CF2E2E` `#F78DA7` `#ABB8C3`）を検出 → `wp-block-library` の CSS が読み込まれている
  - 根拠2: `/works/185/` `/works/140/` という**数値パーマリンク** → `/works/%post_id%/` 構造
  - 根拠3: `/wp-json/wp/v2/types` が **403** → REST API が外部から制限（セキュリティ系プラグインの可能性）
- **WordPress の設置場所: `/wp/` サブディレクトリ**（2026-08-25 判明）
  - メディアURLが `https://kanayama-ss.com/wp/wp-content/uploads/...` の形式
  - つまり「WordPress を専用ディレクトリに配置」する構成（`WP_SITEURL` = `/wp/`、`WP_HOME` = `/`）
  - **テーマの配置先は `/wp/wp-content/themes/<テーマ名>/` になる**
  - REST API は `/wp/wp-json/...` が正しいパスだが、**そちらも 403**。
    外部からは遮断されている（管理画面にログインしたブラウザからは開ける可能性あり）
- **Google Fonts**: 不使用（検出0件）。英字は **Adobe Fonts（Typekit）** を使用

### 3.2 タイポグラフィ

| 用途 | フォントスタック |
|---|---|
| **英字見出し** | `acumin-pro-extra-condensed, sans-serif` ← **Adobe Fonts（Typekit）** |
| 和文・明朝 | `Hiragino Mincho ProN W3` → 游明朝 → `Noto Serif JP` → serif |
| 和文・ゴシック | `Hiragino Kaku Gothic ProN` → Meiryo → sans-serif |
| 汎用 | `Helvetica Neue, Arial, Hiragino Kaku Gothic Pro, …` |

- `acumin-pro-extra-condensed` は全ページで検出（トップ5回、採用6回、その他3〜7回）。

- Webフォントは Adobe Fonts のみ。**継続使用にはライセンス（Typekit キット）の引き継ぎが必要**。

**→ デザインDNA = 「英字コンデンスドの大見出し ＋ 和文明朝/ゴシックの使い分け ＋ グリーン基調」**
