社員紹介の写真をこのフォルダに入れてください。

・ファイル名は自由です。ファイル名の昇順で、社員紹介ページの空いている枠へ
  自動的に割り当てられます（interview-01 → 02 → 03 の順）。
  順番を指定したい場合は 01_〜, 02_〜 のように頭に番号を付けてください。
・推奨は縦位置（3:4）、900×1200px 程度。横位置でも中央基準で切り取られます。
・アップロード後、push すれば GitHub Actions が自動でビルド・公開します。

同じ仕組みで、他のページ用フォルダも作れます（フォルダ名＝ページのスラッグ）。
  例）src/assets/img/message/  → 代表メッセージページの空き枠
      src/assets/img/works/    → 工事実績ページの空き枠
